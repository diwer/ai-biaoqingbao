各 App 自用导入方法

先下载轻量 ZIP，解压并保留 GIF 原文件。不要截图或转换成 JPG；若系统不能将 GIF 保存到相册，可保留在“文件”App 中再选取。以下为个人收藏/聊天使用，不是表情商店上架。

微信

  1. 打开手机微信聊天，点表情按钮，进入爱心/自定义表情页。
  2. 若显示“+”，从相册选择 GIF 添加；也可到“我 → 表情 → 设置/齿轮 → 添加的单个表情”查找添加入口。
  3. 收到或发出可收藏的表情后，可长按查看是否有“添加”选项。没有该菜单时，先保存原 GIF 再从添加入口选择。

小红书

当前未核实存在面向所有账号的整套本地 GIF 批量导入功能。可在私信的相册/图片入口尝试选择 GIF；若发送后长按菜单提供“添加表情/收藏”，再收藏使用。若被转成静态图或无添加入口，说明该版本/场景不支持，不承诺动图可导入。

抖音

进入手机端私信聊天 → 表情 → 收藏/爱心页，若有“+”入口则从相册选择；也可在聊天中长按已支持的表情，查看“添加到表情”等选项。评论区、私信与电脑端能力不同，实际以当前菜单为准，不能保证本地 GIF 在所有入口保留动画。

Telegram

官方 @Stickers 可创建整套安装链接。动态贴纸需将 GIF 转为符合规格的 VP9 WEBM；本项目下载包尚未提供该格式。官方说明。

Signal / WhatsApp

Signal 桌面端提供 Create/Upload Sticker Pack，动图需 APNG，不能直接上传 GIF。WhatsApp 手机端支持创建与分享贴纸包，动图需满足其大小及格式要求；本项目暂无这两个 App 的直接安装包。Signal 说明 · WhatsApp 说明。

核查日期：2026-10-24。微信/小红书/抖音菜单会随系统、版本和账号变化；未在用户手机实测，不把条件性入口写成保证可用。
